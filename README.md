# Alloy Component Library

A collection of reusable Sanity.io components, schemas, and page builder modules for accelerating web development projects.

## Features

- 🧩 Modular components and schemas
- 🔄 Automatic dependency management
- 📦 Simple installation via CLI
- 🛠️ Customizable configuration
- 📚 Built-in documentation
